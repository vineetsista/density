# DENSITY

The flight recorder for AI agents. DENSITY captures everything an agent
produces (traces, transcripts, embeddings), compresses it 10 to 50x with
bit-level techniques, and stores it in tiers priced by guaranteed retrieval
quality. You do not buy compression. You buy "99 percent recall at one tenth
the cost," and DENSITY measures and proves that number on your own data.

## Quickstart

```bash
pip install -e .
density synth --gb 1 --out ./raw            # generate realistic agent traces + embeddings
density audit ./raw --out report.html       # compress, verify recall, estimate savings
density search ./raw.density "user asked about refunds" -k 10
density replay ./raw.density <trace_id>
density bench                               # reproduce the public benchmark table
```

## The tier model

| Tier | Contents | Guarantee (measured, not promised) | Target footprint |
|------|----------|------------------------------------|------------------|
| HOT  | Original fp32 vectors, full traces | Exact | 1.0x |
| WARM | int8 vectors + columnar-zstd traces | recall@10 >= 0.99 vs HOT | <= 0.25x |
| COLD | PQ or binary vectors + dedup'd dict-zstd traces | recall@10 >= 0.95 (PQ) / 0.90 (binary), both with rerank | <= 0.08x |

Recall is always measured on your own data by the recall verifier, and the
audit report prints the measured number next to the guarantee. If measured
recall misses the tier guarantee, the audit says so plainly and recommends
the higher tier.
