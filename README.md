# DENSITY

The flight recorder for AI agents. DENSITY captures everything an agent
produces (traces, transcripts, embeddings), compresses it with bit-level
techniques, and stores it in tiers priced by guaranteed retrieval quality.
You do not buy compression. You buy a measured recall floor at a fraction
of the cost, and DENSITY measures and proves that number on your own data:
the audit report and the benchmark table below carry the measured figures,
never estimates.

## Quickstart

```bash
pip install -e .
density synth --gb 1 --out ./raw            # generate realistic agent traces + embeddings
density audit ./raw --out report.html       # compress, verify recall, estimate savings
density search ./raw.density "user asked about refunds" -k 10
density replay ./raw.density <trace_id>
density bench                               # reproduce the public benchmark table
```

`search` and `replay` read a tiered store directory: `density compress
./raw` builds `./raw.density` from the same corpus without rendering the
report, and `density serve ./raw.density` exposes the same search, replay,
and audit calls over local HTTP.

The same surface is available as a Python SDK:

```python
import density

store = density.open("./raw.density")
store.put_traces("./raw/traces")                  # byte-exact, malformed lines quarantined
store.put_embeddings(ids, vectors, tier="warm")   # int8 vectors, 0.99 recall floor
ids, scores = store.search(query_vector, k=10)
events = store.replay(trace_id)                   # the original events, byte for byte

result = density.audit("./raw")                   # AuditResult, JSON via .to_dict()
```

## The tier model

| Tier | Contents | Guarantee (measured, not promised) | Target footprint |
|------|----------|------------------------------------|------------------|
| HOT  | Original fp32 vectors, full traces | Exact | 1.0x |
| WARM | int8 vectors + columnar-zstd traces | recall@10 >= 0.99 vs HOT | <= 0.25x |
| COLD | PQ or binary vectors + dedup'd dict-zstd traces | recall@10 >= 0.95 (PQ) / 0.90 (binary), both with rerank | <= 0.08x |

Recall is always measured on your own data by the recall verifier, and the
audit report prints the measured number next to the guarantee. If measured
recall misses the tier guarantee, the audit says so plainly and recommends
the higher tier.

One pipeline feeds every surface. Schema-tolerant ingest readers stream
JSONL traces and embeddings; the trace engine shreds events into columnar
dictionary-zstd bundles that replay byte for byte; vector codecs (sq8, pq,
binary) encode embeddings per tier; and a store directory with one
checksummed manifest ties the tiers together. The recall verifier is the
referee: it holds real queries out of your data, computes exact ground
truth, and measures every recall number the audit and the benchmark table
report. The CLI, the Python SDK (`density.open`), and the local HTTP
service (`density serve`) are thin wrappers over the same library calls.

## Benchmarks

Every number between the markers below is generated by
scripts/update_readme_bench.py from measured results in
benchmarks/results/ (written by `density bench`). Benchmark tables are
never typed by hand, and `scripts/update_readme_bench.py --check` exits
nonzero when the table drifts from the newest results, so CI can enforce
that.
